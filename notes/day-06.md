# Day 6：核对翻页重叠与动态字形缓存

日期：2026-11-11

## 本日目标

继续验证村庄通知板与女人长对话的动态字形缓存原型，特别是女人对话滚动翻页期间，旧页和新页同时显示时的字形存活范围。

## 已确认进展

- 用户确认 tile `$D0–$DF` 用于对话框边框纹理、箭头，以及战斗中的中毒等异常状态图标。该范围必须作为保留资源排除出中文字形缓存；当前试点候选仍限于 `$C0–$C9/$CB` 与 `$E0–$FF`，并排除已被第二页引用的 `$CA`。候选结论仅限已检查的两个村庄场景和已测往返。
- T14b3 通知板单字原型已通过：把“中”写入 tile `$E0`（VRAM `$8E00`），通知板首格 `$9842` 临时指向 `$E0`，屏幕正常显示。原图备份至 `$C000–$C00F`，map 原值 `$92` 存于 `$C010`。关闭后按备份手动恢复原图案，最终 map `$9842=$08`；未修改 ROM。
- T14b4 旧试验中，女人对话第一页 `$99C2` 临时显示“中”；第二页完全显示后，再把同一 `$E0` 槽改写为“承”并映射至 `$99C3`。第二页显示正常，翻页完成后的 map 不再引用 `$E0`，而 `$C000–$C00F` 原图备份跨页保持不变。关闭后手动恢复了 `$E0` 原图。
- 用户指出女人对话翻页不是先清除第一页再替换，而是第一页文字上移、第二页文字逐渐浮现，动画期间两页内容会重叠。由此，旧试验只能证明转场完成后的槽位复用，不能证明滚动期间可安全覆盖旧页字形；T14b4 仍未完成，先前的“安全跨页复用”结论撤回。
- 女人正文的 banked ROM 数据范围为 `$030E8E–$030ED1`，终止符 `$7F` 位于 `$030ED1`。`$B9` 宏在 `$030E8E` 展开为「おんな」，其后 `$030E8F` 是 `$7D` 行推进。根据已记录文本与每屏两行布局，正文候选分组为：
  - 前两行：`$030E90–$030EA1`、`$030EA3–$030EB4`；行推进控制码在 `$030EA2`、`$030EB5`。
  - 后两行：`$030EB6–$030EC6`、`$030EC8–$030ED0`；行推进控制码在 `$030EC7`。
  - 该分组需要与翻页中间的画面及 tilemap 快照核对；`$7D` 是行推进，不是显式页分隔符。
- 缓存设计应保守地将相邻两屏的字形并集视为转场期间的存活集合。动画结束且旧页 glyph 不再被 map 引用前，不复用其 tile 槽。源日文样本的两屏分别观察到 19 种和 18 种非空 tile 图案；最终中文译稿的实际并集需另行统计，不能直接沿用单屏 36 格的预算。

## T14b4 运行时观察

- 清空状态下确认 SameBoy 无断点、无监视点；女人第一页完整显示后设置 `$1829` 断点。命中时 PC `$20:$1829`、文本游标 `$0EB6`， map 与第一页基线相符。
- 继续运行后再次在 `$1829` 停下，游标 `$0EC8`；用户确认画面处于前页上移、后页浮现的重叠动画。此时 `$99C0–$9A3F` 中，前页末行从 `$99C3` 起仍被引用，后页首行已在 `$9A03` 起出现；`$FF42/$FF43=$00/$08`。这验证转场中需要同时保留新旧内容对应字形。
- 第二页稳定显示时游标 `$0ED2`，PC `$20:$295F`；`$99C0–$9A3F` 已显示后页两行，前页行内容被后页内容替换。按当前日文样本的静态页统计，两页分别有 19 和 18 种非空 tile，字形并集上界 37，低于 43 个候选槽；最终中文译稿仍需重新统计并集。
- 结论：转场期间按相邻两屏的字形并集保留缓存；转场结束后逐槽检查完整可见 map，只能释放已无任何 map 引用的旧页专用槽，共享 tile ID 仍须保留。先前在第二页稳定后把 `$E0` 从“中”改为“承”的试验只验证了转场后复用；本轮只读观察，未改 VRAM/map/ROM。
- 当前 SameBoy 停在第二页稳定后的 `$20:$295F`；对话仍打开，`$1829` 断点仍安装，无监视点。开始 T14b5 前先检查并清理该断点。
